# App 单设备图标生成提示词（逐张生成）

> 每次只复制一个代码块生成一张图。不要一次要求模型生成网格、合集或多个设备。

## 1. 推荐工作流

1. 把已经生成的 6 宫格图片作为**风格参考图**上传，但要求模型只生成一个设备。
2. 先生成所有设备的默认/关闭状态，确认造型统一后，再用已确认图片做图生图生成开启和离线状态。
3. 优先导出无水印透明 PNG；平台不能生成透明背景时，统一使用纯色 `#F2F2F7`，不要每张随机换背景。
4. 每张保持 `1024×1024`、同一视角、同一光照、主体占比约 65%，不要让阴影接触画布边缘。
5. 建议生成顺序：门铃 → 摄像头 → 网关 → 灯泡 → 墙壁开关 → 插座。六张确认风格后再生成其他类型。

## 2. 通用状态转换提示词

### 开启状态

```text
基于这张已经确认的设备图标做图生图。保持设备外形、材质、视角、位置、尺寸、光照、阴影和背景完全不变，只把设备切换为开启状态：状态指示灯呈清晰科技蓝；如果是灯具，让发光面呈均匀柔和的暖黄色；不要增加任何新零件、文字、图标或背景元素。输出 1024×1024 单设备 PNG。
```

### 关闭状态

```text
基于这张已经确认的设备图标做图生图。保持设备外形、材质、视角、位置、尺寸、光照、阴影和背景完全不变，只把设备切换为关闭状态：灯具不发光，状态灯微弱或熄灭，主体保持珍珠白和浅灰；不要增加任何新零件、文字、图标或背景元素。输出 1024×1024 单设备 PNG。
```

### 离线状态

```text
基于这张已经确认的设备图标做图生图。保持设备外形、材质、视角、位置、尺寸、光照、阴影和背景完全不变，只把整体饱和度降低为浅灰，关闭所有状态灯；不要添加红叉、警告文字、断网符号或其他新元素。输出 1024×1024 单设备 PNG。
```

## 7. 验收标准

每张生成后检查：

- 只有一个设备（门磁允许同一套的两个必要部件）。
- 设备没有被裁切，主体占比与前一张接近。
- 视角都是正面略向右、轻微俯视，不能有的正面、有的侧面。
- 白色材质、蓝色状态灯、阴影方向一致。
- 背景透明，或全部统一为 `#F2F2F7`。
- 没有文字、数字、Logo、水印和多余功能件。
- 国标插座必须是五孔布局，不能生成美规插座。
- 先确认默认/关闭图，再用同一张图做开启和离线状态，禁止重新从文字随机生成状态图。
