# App 设备类型图标生成提示词

> 用途：为 Flutter 智能家居 App 的设备卡片和设备详情页生成统一图标。
> 原则：参考主流智慧家庭产品的清爽卡片视觉，但不复刻任何品牌图标、Logo 或商标。

## 1. 统一生成规范

每次只生成一个设备图标，保持以下参数一致：

- 画布：`1024 × 1024`，正方形。
- 背景：透明 PNG；禁止场景背景、底板、文字和边框。
- 构图：设备居中，占画布约 68%～74%，四周安全留白一致。
- 风格：现代智能家居、轻拟物 3D、圆润几何、柔和磨砂塑料与少量金属材质。
- 视角：正面略带 15° 俯视，所有设备保持统一视角。
- 光照：左上方柔光，右下方非常轻的环境阴影；透明背景下仍保持轮廓清晰。
- 配色：主体珍珠白/浅灰，功能强调色使用科技蓝；发光类设备可增加暖黄色。
- 输出：先保留 1024 px 原图，再导出 512/256/128 px；不要用有损 JPEG。

```text

```

### 通用负面提示词

```text
不要文字，不要字母，不要数字，不要 Logo，不要品牌商标，不要水印，不要人物，不要手，不要房间场景，不要复杂背景，不要底座卡片，不要边框，不要多台设备，不要线稿草图，不要像素风，不要过度写实，不要强烈反光，不要脏污，不要裁切，不要透视变形，不要不对称畸变
```

## 2. 状态变体规范

同一种设备建议生成三套状态，构图和形状必须完全一致，仅改变灯光/颜色：

| 状态 | 视觉要求 | 文件后缀 |
|---|---|---|
| 默认/关闭 | 白灰主体，蓝色指示灯较弱，灯具不发光 | `_off.png` |
| 在线/开启 | 蓝色状态环更明显；灯具发暖黄色柔光 | `_on.png` |
| 离线/故障 | 低饱和灰色，指示灯熄灭，不加红色大叉 | `_offline.png` |

追加提示词示例：

```text
开启状态，保持设备结构和视角完全不变，仅让状态灯呈清晰科技蓝，灯具发柔和暖黄色光，不改变透明背景
```

## 4. App 使用建议

- 首页卡片优先使用 256 px PNG；详情页使用 512 px PNG。
- `DeviceType` 与资源目录建议保持一致：`assets/devices/<type>_<state>.png`。
- 在线开关类设备使用 `_on/_off`；只读传感器使用默认与 `_offline` 两种即可。
- 设备状态信息仍由文字、数值和颜色表达；图标不要承载过多状态，避免可访问性问题。
- 后续如改成 SVG，应沿用同一轮廓、留白和状态配色，不要混用 3D 与线性图标。
