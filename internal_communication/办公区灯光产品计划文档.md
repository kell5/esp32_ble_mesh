# 办公区灯光产品计划文档

## 1. 项目背景
本项目面向办公区灯光控制场景，目标是使用 3 块开发板完成一个可演示、可扩展、可落地的灯控原型：
- 1 块 ESP32-WROOM：仅有 D2 单色 LED，用于状态灯/故障灯/联动演示；
- 2 块 ESP32-S3：板载 WS2812 RGB 灯，用于场景灯效、状态表达和层级演示。

当前阶段优先验证：
- 节点组网
- 主从切换
- 灯光控制
- MQTT 上报/下发
- Vue 管理界面

## 2. 产品目标
### 2.1 业务目标
- 支持办公区灯光的分组控制、场景控制、状态监控。
- 在局域网断网或网关切换时，保留本地联动能力。
- 将灯光状态统一上报到 MQTT 服务器，供前端和后续平台接入。

### 2.2 技术目标
- 节点侧具备自组织能力。
- 网关侧支持主节点切换后自动恢复上传。
- 前端侧支持可视化状态、控制和告警。

## 3. 硬件与角色分工
### 3.1 硬件约束
- ESP32-WROOM：仅 D2 单色 LED。
- ESP32-S3：GPIO48 板载 WS2812 RGB。
- 当前硬件仅用于原型验证，不强依赖额外执行器。

### 3.2 角色定义
- **网关/主节点**：负责对外 MQTT 通信、配置同步、状态汇总。
- **普通节点**：负责接收控制命令、执行灯效、回传状态。
- **前端 Vue**：负责区域、场景、设备列表与告警展示。

## 4. 协议与架构
### 4.1 推荐架构
```
Vue 前端
  ↓
MQTT 服务器
  ↓
网关/主节点
  ↓
BLE Mesh / 节点间转发
  ↓
各开发板 LED
```

### 4.2 数据流
- 下行：Vue → MQTT → 网关 → Mesh 节点
- 上行：Mesh 节点 → 网关 → MQTT → Vue

### 4.3 为什么选这个方案
- 现有硬件以 BLE 能力为主，适合走 BLE Mesh。
- Mesh 负责本地多节点联动，MQTT 负责系统集成与上云。
- Vue 负责快速做出管理台和演示页面。

## 5. 功能范围
### 5.1 第一阶段（原型）
- 三块板完成稳定组网。
- 节点可上报在线/离线状态。
- 支持开关灯和基础灯效。
- 网关可通过 MQTT 收发消息。
- Vue 可展示设备状态并下发控制命令。

### 5.2 第二阶段（试点）
- 分组控制：楼层、区域、工位、会议室。
- 场景模式：办公、午休、会议、下班。
- 定时策略：定时开关、自动熄灯、夜间巡检。
- 告警策略：节点掉线、网关掉线、重连失败。

### 5.3 第三阶段（产品化）
- 多网关部署。
- 权限管理。
- 配置下发与远程升级。
- 统计报表与运维日志。

## 6. 节点表现定义
### 6.1 WROOM 节点
- 正常在线：D2 常亮或慢闪。
- 接收控制：短闪表示已执行。
- 断连：快速闪烁。

### 6.2 S3 节点
- 正常在线：WS2812 显示指定颜色。
- 不同层级：不同颜色区分拓扑位置。
- 断连：红色/白色闪烁提示。

## 7. MQTT 设计建议
### 7.1 Topic 建议
- `office/light/gateway/status`
- `office/light/node/{id}/status`
- `office/light/node/{id}/cmd`
- `office/light/scene/cmd`

### 7.2 Payload 建议
```json
{
  "device_id": "node-001",
  "online": true,
  "layer": 2,
  "state": "on",
  "brightness": 80,
  "ts": 1710000000
}
```

## 8. Vue 页面建议
- 总览大屏：在线数、离线数、当前场景、故障数。
- 设备列表：节点状态、层级、最后心跳时间。
- 分组控制：区域开关、亮度、场景按钮。
- 日志页：MQTT 收发记录、节点重选父节点记录。

## 9. 验收标准
- 三块板开机后可稳定入网。
- 断开 root 后，其余节点可自动重选并恢复通信。
- root 恢复后可重新接管上报。
- MQTT 可稳定收发控制命令和状态。
- Vue 页面可看到节点在线状态和控制结果。

## 10. 风险与注意事项
- 供电不足会导致 brownout，需要稳定电源。
- Mesh/蓝牙网络要注意信号覆盖和干扰。
- 主节点切换后，MQTT 客户端必须做重连。
- WROOM 与 S3 的灯效表现不同，UI 需要统一抽象，不要直接依赖灯的物理差异。

## 11. 里程碑
### M1
三板组网 + 基础灯控。

### M2
网关接 MQTT + 前端页面能控制。

### M3
场景、分组、告警、重选主恢复。

### M4
试点部署与运维优化。
